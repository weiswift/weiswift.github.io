# <font size=5 color='red' face='华文楷体'>Ranger 2.0.0集成CDH6.0.1</font>

相关依赖：

- JDK8 ：用于运行RangerAdmin、RangerKMS
- Python2.7 ：用于Ranger自动化安装
- Maven3.6 ：用于Ranger编译
- RDMS： 用于存储授权策略，存储Ranger用户/组，存储审核日志
- Solr(可选) ：存储日志
- Kerberos(可选) ：确保所有请求都被认证


## <font size=5 color='purple' face='华文楷体'>下载Ranger安装包</font>

- 下载地址：<http://ranger.apache.org/download.html>

- 解压tar包

```shell
tar -zxvf apache-ranger-2.0.0.tar.gz
```

## <font size=5 color='purple' face='华文楷体'>安装git(务必安装)</font>

```shell
yum install -y git
```

## <font size=5 color='purple' face='华文楷体'>准备maven环境</font>

1. 获取maven安装包(链接可能会随着网站的变化会失效)

```shell
wget https://mirrors.huaweicloud.com/apache/maven/maven-3/3.6.3/binaries/apache-maven-3.6.3-bin.tar.gz
```



2. 解压文件

```properties
tar -zxvf apache-maven-3.6.3-bin.tar.gz
```



3. 配置环境变量/etc/profile.

```shell
###maven###
# 这里换成自己的Maven安装路径
export MAVEN_HOME=/usr/local/apache-maven-3.6.3
export PATH=$PATH:$MAVEN_HOME/bin

MAVEN_OPTS=-Xmx2048m
export JAVA_HOME MAVEN_HOME MAVEN_OPTS JAVA_BIN PATH CLASSPATH
```



4. 使环境变量生效

```shell
source /etc/profile
```



5. 修改setting.xml

```shell
vim apache-maven-3.6.3/conf/settings.xml
```



6. 添加如下配置

<mirrors>

## <font size=5 color='purple' face='华文楷体'>编译Ranger</font>

1. 进入apache-ranger-2.0.0目录编译

```shell
mvn -DskipTests -Drat.skip=true -DskipJSTests clean compile package install assembly:assembly
```

## <font size=5 color='purple' face='华文楷体'>安装solr记录审计日志</font>

1. useradd solr

2. 后续操作用root用户即可
3.  `cd /usr/local/apache-ranger/apache-ranger-2.0.0/security-admin/contrib/solr_for_audit_setup`

4. `vim install.properties`

```properties
JAVA_HOME=/export/server/jdk1.8.0_241
SOLR_USER=solr
SOLR_INSTALL=true
SOLR_DOWNLOAD_URL=http://archive.apache.org/dist/lucene/solr/5.2.1/solr-5.2.1.tgz
SOLR_INSTALL_FOLDER=/opt/solr
SOLR_RANGER_HOME=/opt/solr/ranger_audit_server
SOLR_RANGER_PORT=6083
SOLR_DEPLOYMENT=standalone
SOLR_RANGER_DATA_FOLDER=/opt/solr/ranger_audit_server/data
SOLR_LOG_FOLDER=/var/log/solr/ranger_audits
SOLR_MAX_MEM=2g
```

6. 脚本没有运行权限

```shell
chmod -R 755 setup.sh
```



7. 运行自动安装脚本

```shell
./setup.sh
```



8. 启动solr

```shell
cd /opt/solr/ranger_audit_server/scripts
./start_solr.sh
```



9. 安装完成

http://192.168.88.161:6083

## <font size=5 color='purple' face='华文楷体'>安装Ranger-admin</font>

1. 解压

`tar -zxvf ranger-2.0.0-admin.tar.gz `

2. vim install.properties

```shell
#数据库类型选择MySQL
DB_FLAVOR=MYSQL
 
## 指定MySQL的驱动，需要自己准备相应的jar包
SQL_CONNECTOR_JAR=/usr/share/java/mysql-connector-java.jar
 
## 配置MySQL数据库的信息
db_root_user=root
db_root_password=123456
db_host=localhost

#安装时会使用上面的root用户创建如下数据库
db_name=ranger
db_user=ranger
db_password=123456

# 配置RangerAdmin使用DB作为audit审计日志
audit_store=solr
audit_solr_urls=http://192.168.88.161:6083/solr/ranger_audits

#登录ranger-admin的用户名密码：admin/admin
rangerAdmin_password=admin
rangerTagsync_password=admin
rangerUsersync_password=admin
keyadmin_password=admin
```

3. 需要在数据库创建配置的用户和数据库

   ```properties
   grant all on *.* to ranger@'%' identified by '123456' with grant option;
   CREATE DATABASE ranger;  
   FLUSH PRIVILEGES;
   ```


4. 执行如下脚本./setup.sh

5. 启动停止命令

```properties
启动Ranger Admin：
ranger-admin start

停止Ranger Admin：
ranger-admin stop
```



6. 安装验证

web登陆验证是否安装成功：

http://192.168.88.161:6080

默认用户名密码 admin/admin

## <font size=5 color='purple' face='华文楷体'>安装Ranger-usersync（用户同步服务）</font>

1.     解压

```shell
tar –zxvf ranger-0.6.0-usersync.tar.gz
```

2. vi install.properties

```properties
POLICY_MGR_URL = http://192.168.88.161:6080
SYNC_SOURCE = unix
MIN_UNIX_USER_ID_TO_SYNC = 500
```

3. vim /etc/ranger/usersync/conf/ranger-ugsync-site.xml

```properties
<name>ranger.usersync.enabled</name>
<value>true</value>
```

4. 使用root用户执行如下脚本安装Usersync:

```properties
./setup.sh
```



5. 使用root用户启动Ranger Usersync：

```properties
./ranger-usersync-services.sh start 或者ranger-usersync start
```



6. 修改RangerAdmin 的 Authentication Modes：

- ranger-admin stop
- vim install.properties

```properties
authentication_method=UNIX
remoteLoginEnabled=true
authServiceHostName=172.17.8.85
authServicePort=5151
```

7. 执行如下脚本./setup.sh

8. 启动停止命令

ranger-admin start

9. 验证是否安装成功

`同步Linux系统用户到ranger数据库,在RangerAdmin的web控制台可以看到users中同步的用户信息。`

## <font size=5 color='purple' face='华文楷体'>安装Ranger-Elasticsearch-Plugin</font>

1. 解压ranger-2.0.0-elasticsearch-plugin

`tar -zxvf ranger-2.0.0-elasticsearch-plugin.tar.gz`

2. vim install.properties

```properties
#ranger地址
POLICY_MGR_URL=http://172.17.4.9:6080
#服务名称

```

3. 用root用户运行enable-elasticsearch-plugin.sh来启用es插件

## <font size=5 color='purple' face='华文楷体'>安装Ranger-Hive-Plugin</font>

> Ranger Hive-plugin是Ranger对hive进行权限管理的插件。Ranger Hive-plugin只能对使用jdbc方式访问hive的请求进行权限管理，hive-cli并不受限制！
>
> 也就是说不可对外提供cdh集群节点，只可让对方通过jdbc的方式上传数据

1. 解压

`tar -zxvf ranger-2.0.0-hive-plugin.tar.gz`

2. vim install.properties

```properties
#策略管理器的url地址
POLICY_MGR_URL=http://172.17.4.9:6080
#组件名称可以自定义
REPOSITORY_NAME=hivedev
#hive的安装目录
COMPONENT_INSTALL_DIR_NAME=/opt/cloudera/parcels/CDH-6.0.1-1.cdh6.0.1.p0.590678/lib/hive
#是否保存审核日志
XAAUDIT.SOLR.ENABLE=true
#用来存储审核日志的solr地址
XAAUDIT.SOLR.URL=http://172.17.4.9:6083/solr/ranger_audits
#hive组件的启动用户
CUSTOM_USER=atguigu
#hive组件启动用户所属组
CUSTOM_GROUP=atguigu
```

3. 将hive的配置文件作为软连接安装到Ranger Hive-plugin目录下：

```shell
ln -s /opt/cloudera/parcels/CDH-6.0.1-1.cdh6.0.1.p0.590678/lib/hive/conf/ conf
```



4. 先在界面添加hive的服务，启用Ranger Hive-plugin后添加测试联通会没有权限

5. 使用root用户启用Ranger Hive-plugin

`./enable-hive-plugin.sh`

6. 重启hive
