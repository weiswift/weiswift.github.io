# 科目二

`上车首先是踩离合刹车，调整座椅坐姿与平时练车保持一致，调整好左右两侧后视镜，系好安全带，手刹松到底，挂入一档`。

1，调整座椅高度，踩刹车退的弯度

2，调整后视镜

3，系好安全带

4，松手刹，挂一档



倒车入库（`停车超2s 扣5分/次，超过210秒、不按路线顺序、不入库、车身出线、车轮压线、后轮过线扣100分`）

要领：`一、调整座椅和坐姿点位尽量固定；二、放慢车速；三、会修方向`



`缓慢驶入，走直后，方向盘回正，肩膀与黄线平行就停车，停车后挂入倒挡`

## 左倒库

`左后视镜，镜子下边缘与黄线重叠，迅速向左打满方向（向左看←）`

（如果是左倒库需要肩膀到达黄标记线--考场可能没有）

（如果是右倒库）

`左后视镜将要看不到库角回半圈，到点后方向向右回半圈（方向盘回正）`，观察左侧宽度是否危险，有些窄可以提前回正方向

继续观察左侧后视镜，左侧宽方向继续向左侧调整，车辆走直后回正方向倒库。

快到停车点后，观察左侧后视镜下沿与黄线重叠就停车。在进库时，车轮车身不能扫线，压线，`车辆停到库内后挂入前进档`

`缓慢驶入，走直后，方向盘回正，肩膀与黄线平行就停车，停车后挂入倒挡`

## 右倒库

`观察左后视镜下沿与黄线重叠，方向盘迅速向右打满方向（向右看→）`

`观察右后视镜，中后门把手到达最后一根虚线中间位置，方向盘迅速向左回半圈（就是方向盘回正）。`

## 侧方位停车

> （车身碰线、不打灯/错打灯扣10分，车身出线压实线库角、超90s扣100分）

雨刮器一直沿着线行驶，开到停车点后停车，挂入倒档

`第一个点位，观察右侧后视镜，库脚消失，方向盘向右打满。`

`第二个点位，左侧后视镜内看到裤脚后，方向盘迅速回正。`

`第三个点位，抬头看后轮即将压到虚线，方向盘迅速向左打满方向`

`车辆走直后停车，停车→开启左转向灯→再挂入前进挡（转向灯必须达到3秒钟以上再出库）。`

## 曲线行驶

> （停车超2s 扣5分/次，车轮压线扣100分）

车辆往中间行驶，靠切线行驶，抬起身，看左侧灯脚位置与黄线重叠，方向盘向左打一圈，始终让左侧灯脚一直沿着黄线行驶，如果发现偏移，需要微调方向盘。

车辆走到曲线行驶中段位置时，看左侧车灯与黄线重叠，迅速向右回正方向盘

看雨刮器位置与线重叠，方向盘向右打一圈，观察雨刮器位置始终沿着黄线行驶，可以微调方向，哪边宽就往哪边调





## 上坡起步（C2走一遍即可）

雨刮器始终沿着黄线行驶，如果发现偏移需要左右微调方向，注意看左侧停车场，点镜子下沿能够看到中间桩杆线就停车，停车后拉起手刹达到3秒以上，松下手刹需要在30秒内完成起步。仔细看非常关键的部分，慢松离合器至半联动，车身会出现明显抖动当车身出现明显抖动，离合器定住不动，接着把刹车松掉。车辆完成起步后，方向盘向左微调，防止压右侧黄实线导致挂科。车辆往中间行驶，不要压到两侧黄线，下坡时注意控制车速，别踩油门，防止起飞。考试中是可以停车的，必须停在黄线区域外



## 窄路掉头

往前走，方向盘的12点钟位置走左半边马路正中间走/稍偏右边一点点，一直往前开。

第一个点车头接近碰线的时候，往左一圈半打满

![img](https://wei-blog.oss-cn-beijing.aliyuncs.com/24-07/cc27359668204377b16657ac0ac4ee72.png)

第二个点可以用车窗边的这个3分之1的位置跟黄线相交好停车（停好车再打方向盘）。

![img](https://wei-blog.oss-cn-beijing.aliyuncs.com/24-07/5a08de7fa66947cc9450fa5d1a44ca27.png)

停好车之后，挂倒档，快速方向盘往右三圈打满

观察左后轮位置，左后轮离快压黄线（此时车头基本摆正/摆正稍往左边歪一点点）

停车挂前进档，方向盘往左打满三圈了，又是打满之后好走出来。车身走直走正，方向盘回正，窄路掉头完成。

## 上车准备、灯光、起步、下车

> 上车：绕车一周、调座椅后视镜、安全带（不急着）【不逆时针绕车-四个点位，开门前不看后面就开门、未系安全带】统统扣100分。
>
> - `绕车`：逆时针绕车，按感应器一定要**长按**，听到“滴”声或语音播报再松手，千万别摸一下就跑。
>
> 灯光：（上车第一项、必考、5s内反应不急、不抢指令）【灯光错误、临时停车（少开灯）-开示廓灯+双闪灯、雾天开远光、结束未关灯】统统扣100分。
>
> - `灯光：`听完语音播报后，有5秒的反应时间。**绝不抢答！** 哪怕你知道下一句是什么，也必须等语音播完再拨灯杆。远近交替（挑两下）切忌用力过猛。
>
> 起步：（2+2+1原则）上面操作两个（转向灯，喇叭）下面操作两个（挂一档，松手刹）最后左右观察，确定周边安全，慢松刹车起步。【`车门未关起步、起步前不观察内外后视镜+左后盲区、转向灯不足3s`、溜车>30cm、手刹未松到底且未及时调整】扣100分；《溜车<30cm、松手刹10s内未起步、熄火1次》扣10分；`忘记鸣喇叭扣5分`。
>
> - `操作`： 打左转向灯（等3秒） -> 按喇叭（响2下） -> 踩刹车 -> 挂D挡 -> 松手刹 -> 夸张地左右看后视镜 -> 缓松脚刹，轻点油门起步。
>
> - `注意：` 起步后尽快将车身顺直，转向灯会自动关闭，没关就手动关闭。

`流程`：上车→身份证交给安全员→下车逆时针绕车一周（长按感应器有播报） → 回到车上 → 系好安全带 → 调整座椅（后视镜一般跟科目二不一样） → 踩刹车点火（不挂档位、不松手刹） → 模拟灯光考试 → 关闭所有灯光 → 起步

`灯光介绍：`

- 灯光总闸（上来关闭的、扭一下是示廓灯、在扭一下是前照灯）

- 远近光灯（往前变蓝远光灯、往胸前拨近光灯、往胸前拨两下就是远近光交替）

- 危险双闪灯（按下开启，按下关闭）、打开前照灯（扭两下）

![image-20260620163844566](https://wei-blog.oss-cn-beijing.aliyuncs.com/24-07/image-20260620163844566.png)

不良道路（远光灯）、夜间通过急弯（远近光灯交替--不要太快）、`前方通过有信号灯路口（近光灯）`

夜间同方向近距离跟车行驶（近光灯）、夜间与机动车会车（近光灯）、夜间超车（）、请关闭所有灯光（扭两下）

`起步`： 打左转向灯（等3秒） -> 按喇叭（响2下） -> 踩刹车 -> 挂D挡 -> 松手刹 -> 夸张地左右看后视镜 -> 缓松脚刹，轻点油门起步。

## 直线行驶

> - **技巧：** 视线**放远到100米开外的车道正中心**。C2没有换挡干扰，你可以很平稳地稳住油门，将车速保持在 30-40km/h 之间。车速太慢反而容易跑偏。
> - **微调：** 发现车头有偏移趋势，方向盘只能有“几毫米”的微调（打一点点立马回正），绝对不能超过5度。

直线行驶这个项目想要顺利通过不挂科，就一定要知道考试的标准和考试的规则，

`第一个评判标准就是播报直线行驶之后要在100米或者120米的距离保持车辆直行`。如果车辆在车道的左侧播报的直线行驶，那你就一直要靠左侧保持直行。如果是车辆靠右或者在中间也是同样的道理。你不能说本来车辆是在车道的左侧播报的直线行驶，走着走着你发现，我车道是不是偏左了，我方向盘往右边调中一点行不行？不行了，你就只能一直靠着左侧行驶。在考试的时候，如果说你的车辆一直向左侧或者一直向右侧偏离了30公分，超过30公分，那就会直接挂科。

`第二个误区就是在走直线不一定就是方向盘不动就能够保持直行。`我告诉你，只有不会教的教练才会用这种方法。为什么？第一个，你每台车的轮胎胎压不一样，你每台车的方向盘间隙它是不一样的，有的车子你要稍微偏一点才能走直。第三个，你不知道这个学员他到底有没有把方向盘端平，这是一回事。如果说你运气好的话，你用这个方法可以过，你运气不好你就直接挂科了。就会导致学员有一个什么样的情况，教练叫我不要动，那我就不动，结果挂科了。

`调方向盘的幅度过大，超过五度会直接挂科`。什么是五度？你看这个标准就没有超过五度，它就不会挂科。那如果说这个标准，那就超过五度了，直接挂科了，这就是原因。调方向能不能调走直线，我告诉你可以调微调回正，`微调回正`。如果车辆会走偏，微调回正微调回正，微调回正，这样的话就不会挂科。`快调（右）快回（正）`

`直线行驶之后，我们视线看远，一定要看远处，你才能发现这个车辆是否会跑偏`。如果说你看的太近了，那你肯定是看不出来了。贴对联的时候你是不是要站远一点，你才看得出来贴的正不正。

`车速尽量控制在35码到45码之间`。看车速的时候你不能一直盯着仪表，因为你车子会走偏，你要看一眼仪表盯着前面，看一眼仪表盯着前面，你的主要视线一直是观察在前面，你按照这个方法来练习，你就能找到车感，你就能把车子走直。

| 错误情形                                        | 扣分 |
| ----------------------------------------------- | ---- |
| 方向把控不稳，车辆大幅跑偏、左右偏移过大        | 100  |
| 长时间单手不能稳住方向盘、双手同时离方向盘      | 100  |

## 变道&超车&会车

> **口诀：** 打灯 -> 默数3秒同时左右看 -> 缓打方向（30度左右） -> 进道后回正 -> 关灯。

### 变更车道

> 

先开启左转向灯 → 转向灯达3秒以上 → 观察后方没来车→方向盘向左打35度（不跳灯）→ 驶入左侧车道 → 回正方向盘 → 注意不要压到实线 → 关闭转向灯项目完成

| 错误情形                                 | 扣分 |
| ---------------------------------------- | ---- |
| 转向灯开启不足 3 秒转动方向盘            | 100  |
| 变道前不观察后视镜、不回头看目标车道后方 | 100  |
| 一次性连续变更两条及以上车道             | 100  |
| 变道过程压实线、影响后车正常通行         | 100  |
| 变道完成后长期不关闭转向灯               | 10   |

先开启左转向灯 → 达到3秒以上 → 观察后方没来车 → 方向盘向左侧打35度（防止跳灯） → 驶入左侧车道 → 方向盘调整车辆走直 → 关闭左转灯 → 立即开启右转向灯 → 达到3秒以上 → 左侧车道行驶一段距离 → 稍微加点油提点速 → 左右观察没来车 → 返回原车道 → 注意不要压到右侧的实线 → 关闭转向灯

## 路口转弯&掉头

> - `红灯停车：` 如果要在路口等红灯，踩死刹车停稳。**在上海考场，建议停稳后推入N挡（空挡）并拉起手刹**。绿灯亮起再踩刹车挂D挡起步。千万不要挂在D挡长时间踩着刹车，脚一酸松开溜车就挂科。

## 注意

### 灯光、观察、刹车

1. **转向灯绝对的“3秒定律”**
   - **雷区：** 起步、变道、超车、掉头、靠边停车，只要打转向灯，**必须在心里默数“1001、1002、1003”后，才能动方向盘**。差0.1秒动方向盘，直接扣100分。
   - **跳灯陷阱：** 如果方向盘打得太快导致转向灯自动弹灭，且车辆还未完全进入目标车道，**必须立刻、马上补打！**（建议用手指轻轻压住拨杆防止跳灯）。
2. **夸张的“摇头式”观察**
   - **雷区：** 起步、变道、过路口等环节，不仅要看后视镜，上海考场的探头或安全员必须看到你**有明显的“左右摆头”动作**。只动眼珠子不动头=没观察=挂科。
3. **“隐形”的刹车感应区**
   - **雷区：** 通过**学校区域、公交车站、无红绿灯的人行横道**。这三个地方**没有语音播报**！
   - **绝招：** 只要看到路边有这三个标志，或者看到地上的菱形减速标线，不管当时车速多慢，右脚必须从油门移到刹车上，**结结实实地踩一脚刹车（要让系统感应到车速下降）**，同时左右大幅度摆头观察。

### N档与P档对比

| 对比项         | P 挡（驻车挡）                                           | N 挡（空挡）                                  |
| -------------- | -------------------------------------------------------- | --------------------------------------------- |
| 锁止原理       | 机械卡扣锁死变速箱传动轴，车轮抱死不能溜车               | 动力完全切断，无锁止，车子受外力会溜动        |
| 适用场景       | 长时间停车、熄火锁车、停车过夜                           | 临时等红灯、拖车、挪车、堵车短时怠速          |
| 手刹配合       | 平地可单用 P 挡；坡道必须拉手刹 + P 挡，防止锁钩受力变形 | **无论平地坡道，挂 N 挡必须拉紧手刹，必溜车** |
| 能否推车拖车   | 严禁拖车、推车，极易打坏 P 挡锁齿                        | 可以短距离拖车、推车挪车                      |
| 科目三下车规范 | 停车最终必须挂 P 挡熄火                                  | 不能用 N 挡代替停车收尾挡位                   |

### 附原文 - 科三16项目

一条视频学会科目3，16个项目，视频很长，记不住的同学收藏起来，以免考前找不到。祝大家考试都能够逢考必过。上车之后，咱们先把`身份证交给安全员`。第一个项目就是`逆时针绕车下车观察左侧的后视镜`，有车让他先走。逆时针绕车必须要从左侧的车尾。需要注意的是考试车上一般会有2到4个感应器，分别在四个角落。咱们要逆时针绕车，触碰感应器，要`长按感应器`，按感应器的时候，它会有语音播报，如果没有语音播报，说明你的感应器没有按到位。

绕车一周的目的是为了检查车辆的周围环境，看看周边有没有小动物之类的。好，咱们上车。上车之后，`确定灯光的位置`（`指0重打轻回点抬`），在近光灯，可以远近灯光交替一下，确定它在近光灯，确定档位是在空挡，接着`系好安全带`。不要系错了，回拉一下。系好安全带之后，踩住刹车点火启动车辆。因为车辆是没有点火的，需要踩住离合，`踩住刹车点火启动车辆`。

打着火之后，就是第二个项目模拟灯光考试了。先给大家来说一下这个灯光怎么操作。指向零就是关闭，扭一下就是示廓灯，再扭一下就是前照灯。远近灯光的位置在这里往前一推，有个蓝色的标识，那就是远光灯。往胸前拨一下，那就是近光灯了。往胸前拨两下就是远近灯光交替，这个红色的三角形就是危险双闪灯，按一下开启，按一下关闭。

模拟灯光考试的题目都给你们归类好了，可以自己保存。那么我们来做一组模拟灯光考试，下面将进行模拟等待语音，听到语音提示后，请在5秒内做出相应的灯光操作。别着急，`请打开前照灯`，开灯扭两下好了。`不良道路`开远光灯往前推，`夜间通过急弯`，急弯返回近光灯。在远近灯光交替`前方通过有信号灯路口`，有信号灯路口，近光灯灯光位置在近光无需操作。夜间`同方向近距离跟车行驶`，跟车行驶，近光灯灯光位置在近光无需操作。`夜间与机动车会车`近光灯模拟夜间考试完成，请关闭所有灯光，模拟夜间考试完成，关闭所有灯光，灯光就做完了。

在做灯光的时候一定要注意不能抢语音，`不能抢指令`。即使你知道答案，你必须`等它播报完成之后再进行操作`。再进行操作灯光的时候一定要特别注意，这个灯杆往前推是远光灯对吧？返回近光灯的时候你不要太用力了，`太用力了你会拨到这个远近灯光交替`。然后在交替的时候，你不要太快了，`太快了有的时候电脑会感应不到`。所以我们交替的时候，远近灯光交替模拟灯光。考试完成之后就会播报起步行驶的指令，请立即起步，按语音提示完成考试。`起步行驶记住2加2加1的原则`，`上面操作两个转向灯喇叭，下面操作两个挂一档。松手刹，最后左右观察，确定周边安全，慢松刹车起步`。

今天学的五个项目里面都会用到转向灯，但是转向灯它有三个隐藏的坑。

第一个，比如咱们开了转向灯之后，要变道超车的时候，`转向灯的秒数没有达到3秒钟以上，你方向盘一转直接挂科`。

第二个坑就是临时的转向灯，很多同学因为紧张，然后轻轻的往下面拨一下，他只会开一个临时的转向灯，3秒钟之后自动关闭了。像这种情况也是考试直接挂科的。所以咱们在使用转向灯的时候，一定要`重打轻回`。你看往下一拨，这就是一个长时间的转向灯了。

第三个坑就是在考试的过程当中，转向灯会自动关闭。`开了转向灯方向盘向左侧打45度回正，转向灯自动关闭，开了右转向灯，方向盘向右侧打45度回正，转向灯自动关闭`。所以咱们在使用转向灯的时候，不要超过了45度，`可以微调方向不超过45度，它就不会关转向灯了`。

在完成项目的时候，比如说超车变道，咱们`在这条车道要过去那条车道，转向灯需要达到3秒钟`。如果说`在这条车道的转向灯没有达到3秒钟，或者说转向灯自动关闭了，我们需要立即补灯`。在项目前转向灯自动关闭了，关闭了要立即补灯。如果说变道的时候，车辆已经转到中途了，或者已经过去了，转向灯自动关闭的话，那就不需要补灯了。请变更车道。

在`变道时先开启左转向灯`，转向灯达到3秒钟以上左右，观察之后确定后方没有来车，方向盘向左侧打35度左右，不会跳灯驶入左侧车道，回正方向盘，注意不要压到实线，回正方向盘，关闭转向灯项目完成，前方请完成超车动作，先开启左转向灯，达到3秒钟以上左右，观察确定后方没有来车，方向盘向左侧打35度，防止跳灯。走到左侧车道之后，把方向盘向右侧调整，把车辆走直，记住关闭左转灯，立即开启右转向灯。转向灯必须要达到3秒钟以上，在这条车道上必须要行驶一段距离，稍微加点油提点速，左右观察。后面没有来车返回原车道，注意不要压到右侧的实线，关闭转向灯，前方左转弯，左转弯前开启左转向灯，防止扣100分。快红灯了需要在停止线前停车，如果是绿灯的情况，可以在停止线前点刹车减速，左右观察之后再通行。红灯停车后挂入空挡，踩住刹车等待，防止溜车。

绿灯之后踩离合，挂入一挡，左右观察之后起步。当车头看不见斑马线时，方向盘向左侧打90度，此时因为左转的距离远，考试中一档的行驶距离不能连续超过50米，所以咱们打完方向盘之后，需要加点油门，踩离合换二档。驶入车道之后，转向灯自动关闭，前方右转弯，右转弯时提前开启转向灯。路口没有其他车辆，没有红灯箭头，可以不需要停车。在停止线前点刹车减速，左右观察，确定安全之后再通过。车头看不见斑马线时，方向盘向右侧打180度。打方向盘的角度它并不是固定的，是根据你转弯的距离和你的车速来决定的，也就是说转弯的距离越短打方向盘的幅度就越大。

掉头项目先开启左转向灯，驶入左侧掉头车道。前面掉头的时候要稍微注意一下，尽量停车减速，把车速降下来，因为前面有对向来车，接着咱们挂个空挡，确定转向灯是亮起状态，起步时挂入一档，用一档来掉头。对方没有来车了，咱们确定安全了，要观察方向盘向左侧直接打满。实路车到之后，回正方向盘加油，挂个二档继续完成考试。

今天咱们学的这五个项目里面用到最多的就是刹车。刹车谁都会问题是什么项目要踩，什么时候踩？如果考试的时候踩熄火了，要怎么样挽救自己的成绩？
