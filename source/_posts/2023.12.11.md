# <font size=5 color='red' face='华文楷体'>什么是Ranger</font>

> Apache Ranger是一个Hadoop平台上的全方位[数据安全](https://so.csdn.net/so/search?q=%E6%95%B0%E6%8D%AE%E5%AE%89%E5%85%A8&spm=1001.2101.3001.7020)管理框架，它可以为整个Hadoop生态系统提供全面的安全管理。
>
> 安装Apache的软件要注意一点，就是各个版本的兼容性问题。

# <font size=5 color='red' face='华文楷体'>Apache Sentry和Ranger优缺点</font>

> 一般来说：**CDH自带的是Sentry，HDP的是Ranger**。
>
> **Sentry**是由Cloudera公司内部开发而来的，所以Sentry对HDFS，Hive以及同样由Cloudera开发的Impala有着很好的支持性.
>
> **Ranger**则是由于另一家公司Hortonworks所主导。相比较于Sentry而言，<font size=4 color='red' face='华文楷体'>它能支持更丰富的组件</font>，包括于 HDFS, Hive, HBase, Yarn, Storm, Knox, Kafka, Solr ,NiFi。
>
> <font size=4 color='green' face='华文楷体'>早期CDH版本只提供sentry的权限管理方案，后期新版本提供ranger作为替换方案</font>，而CDH只有商业版本提供sentry升级ranger的服务，开源社区版并未提供这样的能力，可以说Ranger是Sentry的一个升级版。
>
> 两个组件的比较如下：
>
> - Apache Ranger 拥有自己的 <font size=4 color='red' face='华文楷体'>Web 用户界面 (Web UI)</font>
> - Ranger Web UI 也可用于安全密钥管理，使用 Ranger KMS 服务的密钥管理员可以单独登录。
> - Apache Ranger 同时提供了<font size=4 color='red' face='华文楷体'>Restful</font>接口，就是用URI表示资源，用HTTP方法(GET, POST, PUT, DELETE)表征对这些资源的操作。
> - Apache Ranger 还提供了非常需要的安全功能，例如开箱即用的<font size=4 color='red' face='华文楷体'>列掩码和行过滤</font>。
> - Ranger 中的访问策略可以使用不同的属性（如地理区域、一天中的时间等）在动态上下文中进行自定义。下表给出了 Sentry 和 Ranger 之间功能的详细比较。

# <font size=5 color='red' face='华文楷体'>Apache Sentry和Ranger权限比较</font>

#### Sentry权限控制

<font size=4 color='green' face='华文楷体'>Sentry是典型的RABC权限管理系统</font>，通过用户-用户组-角色关联，最终通过role来进行赋权，一般只用于<font size=4 color='red' face='华文楷体'>表</font>级授权，存在三种权限类型：<font size=4 color='red' face='华文楷体'>select/insert/all(*)</font>。

![](https://wei-blog.oss-cn-beijing.aliyuncs.com/img/Snipaste_2023-12-14_10-38-25.png)

- sentry_role: 角色列表
- sentry_group；用户组列表
- sentry_role_group_map；角色、用户映射关系表
- sentry_db_privilege: 表权限信息表
- sentry_role_db_privilege_map: 权限、角色映射关系表

- Policy的灵活性

通过的Policy策略还有许多灵活的特性，包括它还能支持基于Tag的策略控制，有了Tag后，就无需考虑组件的差别了。另外还有condition的条件的添加控制，这些也都是由管理员用户人工控制的。

同样的，Ranger Plugin程序会拉取策略数据在本地，如果说Ranger admin server临时不可用了，也不会影响策略实际的执行认证。

# <font size=5 color='red' face='华文楷体'>总结及给出建议</font>

> - Sentry在于它对于Hive等相关组件支持集成的比较好（跟CDH同根同源）。
>   - 一般通过用户角色进行权限的控制，通常能控制在表级。
> - Ranger在于它更通用化的支持和更加丰富的策略控制。
>   - 通过Policy进行权限控制，配置策略非常灵活。

总结：Apache Ranger提供了Apache Sentry在CDH中提供的所有功能。Ranger是一个全面的解决方案。它还提供了额外的安全功能，如数据过滤和屏蔽，增强了数据安全策略。
