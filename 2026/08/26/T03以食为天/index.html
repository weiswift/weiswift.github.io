T03以食为天

Created2026-08-26|Updated2026-08-28
|Post View:

吾生也有涯，年轻时的我们需要将时间用在能够提高生命厚度的一些事情上，我认为重要的就是注意力、时间、金钱。做饭什么时候都可以做，所以我会将我的做饭时间压缩到最低，由此注意力才有可能放在更有意义的一些事情上，因此有了这篇制作人类冻干的博客，以减少做饭时间，将年轻的时候的注意力放在事业等别的地方。（需要用空气炸锅 的没有列举出来）

食材

蛋白质来源：鸡蛋、猪瘦肉、猪肉末、香干（豆腐干）、北豆腐、嫩豆腐、鸡胸肉、鸡腿肉、肥牛卷、牛肉片、牛肉卷、牛腩、三文鱼、龙利鱼鱼片、猪排骨

维生素/膳食纤维来源：番茄、青椒、茄子、土豆、洋葱、黄豆芽、白萝卜、大蒜、胡萝卜、甜玉米粒、青豆、金针菇、香菇、青菜、菌菇合集、魔芋结、卷心菜、马蹄、娃娃菜、荔浦芋头

碳水来源：白米饭、杂粮饭 / 低糖饭、土豆、芋头、淀粉（勾芡）、白糖、冰糖、番茄酱糖分、咖喱块碳水、椰浆碳水

脂肪来源：烹调用植物油、香油、肥牛 / 牛肉 / 牛腩自带脂肪、三文鱼鱼油、鸡皮油脂、猪肉脂肪、排骨自带脂肪、咖喱块油脂、椰浆油脂

一周五天懒人&穷鬼

周一：番茄鸡蛋浇头 周二：青椒豆干肉丝浇头 周三：土豆茄子肉末浇头 周四：香菇豆腐浇头 周五：豆芽肉片浇头

参考链接：5元预算，5min开饭！一周懒人&穷鬼盖饭！

周一｜番茄鸡蛋盖浇头

食材：番茄 2 个、鸡蛋 2 个、食用油、盐、少许白糖、淀粉水

  1. 鸡蛋打散，锅里放油炒熟，盛出备用
  2. 番茄切块下锅翻炒至出沙，放少许白糖中和酸味，加盐调味
  3. 倒回鸡蛋，翻炒均匀，淋少量淀粉水收浓汤汁
  4. 放凉后分装保鲜盒，冷冻保存。食用时微波加热后浇在米饭上

营养构成

  • 蛋白：鸡蛋 ‑ 维生素 / 膳食纤维：番茄 ‑ 脂肪 / 碳水：食用油、米饭

周二｜青椒豆干肉丝浇头

食材：猪瘦肉、香干（豆干）、青椒、生抽、盐、淀粉、食用油

  1. 瘦肉切丝，加少许生抽、淀粉抓匀腌 10 分钟
  2. 豆干切条、青椒切丝
  3. 起锅倒油，下入肉丝滑炒至变色
  4. 放入豆干、青椒丝翻炒，加盐、生抽调味翻炒 2‑3 分钟
  5. 放凉分装冷冻，复热配米饭

营养构成 ‑ 蛋白：猪瘦肉、香干 ‑ 维生素 / 膳食纤维：青椒 ‑ 脂肪 / 碳水：食用油、米饭

周三｜土豆茄子肉末浇头

食材：猪肉末、土豆、茄子、生抽、盐、食用油

  1. 土豆、茄子切小丁；茄子可以先用盐腌一会，挤掉黑水减少吸油量
  2. 锅里放油，肉末下锅炒散炒熟
  3. 倒入土豆丁、茄子丁翻炒，加少量清水盖上锅盖焖煮至土豆变软
  4. 放生抽、盐调味，大火稍微收一下汤汁
  5. 晾凉分装冷冻，复热浇米饭

营养构成 ‑ 蛋白：猪肉末 ‑ 维生素 / 膳食纤维：茄子、土豆 ‑ 脂肪 / 碳水：食用油、土豆淀粉、米饭

周四｜香菇豆腐浇头

食材：北豆腐、鲜香菇、生抽、盐、食用油、少量淀粉水

  1. 豆腐切小块，香菇切片
  2. 锅中放油，香菇下锅炒香
  3. 放入豆腐，轻轻翻炒，加少量清水焖 2‑3 分钟
  4. 生抽、盐调味，淀粉水勾芡，汤汁浓稠关火
  5. 放凉分装冷冻

营养构成 ‑ 蛋白：北豆腐 ‑ 维生素 / 膳食纤维：香菇 ‑ 脂肪 / 碳水：食用油、米饭

周五｜豆芽肉片浇头

食材：猪瘦肉、黄豆芽、生抽、盐、淀粉、食用油

  1. 猪肉切片，淀粉 + 生抽抓匀腌制
  2. 起锅放油，肉片炒至变色盛出
  3. 黄豆芽下锅大火翻炒 2 分钟
  4. 肉片倒回锅里，加盐、生抽调味翻炒均匀
  5. 晾凉，分装冷冻，吃的时候加热配米饭

营养构成 ‑ 蛋白：猪瘦肉 ‑ 维生素 / 膳食纤维：黄豆芽 ‑ 脂肪 / 碳水：食用油、米饭

一周十元懒人盖饭

参考链接：一周10元懒人盖饭合集！随吃随取，5min上桌！

通用冷冻备餐操作要点

  1. 浇头一定要完全放凉，再装进保鲜盒，热的时候密封会产生水汽，容易变质
  2. 浇头和米饭分开装盒，不要混在一起冷冻米饭，米饭反复冷冻口感很差
  3. 冷冻可以存放 2‑4 周；吃的时候浇头微波炉高火 3‑4 分钟，再浇到热米饭上即可

周一｜青椒肉丝盖饭

食材：猪瘦肉丝、青椒、大蒜 酱汁：生抽、蚝油、少许白糖、淀粉、清水 做法

  1. 瘦肉丝加少许生抽、淀粉抓匀腌制 10 分钟；青椒切丝，蒜切片。
  2. 锅里倒油，下蒜片爆香，倒入肉丝翻炒至变色。
  3. 放入青椒丝大火翻炒 1‑2 分钟。
  4. 倒入调好酱汁，翻炒至汤汁浓稠，关火放凉，分装冷冻。

周二｜三色鸡肉盖饭

食材：鸡胸肉 / 鸡腿肉切丁、胡萝卜丁、玉米粒、青豆 酱汁：生抽、蚝油、少许糖、清水 做法

  1. 鸡肉丁腌制去腥。
  2. 锅里放油，下鸡肉丁翻炒到变色。
  3. 倒入胡萝卜、玉米、青豆翻炒片刻。
  4. 淋入酱汁，盖上锅盖小火焖 3 分钟，开盖大火收汁变浓稠，放凉分装冷冻。

周三｜番茄肥牛盖饭

食材：肥牛卷、番茄 2 个、洋葱半个 酱汁：生抽、蚝油、少许白糖 做法

  1. 肥牛沸水焯 10 秒捞出，去掉血沫。番茄切块，洋葱切丝。
  2. 锅中倒油，下洋葱炒软，放入番茄翻炒，炒出番茄汁水。
  3. 放入焯过水的肥牛，倒入酱汁，翻炒均匀，小火煮 2 分钟收汁。
  4. 放凉，分装冷冻。

周四｜菌菇豆腐盖饭

食材：嫩豆腐、金针菇、香菇、小青菜 酱汁：生抽、蚝油、少许白糖、水淀粉 做法

  1. 豆腐切小块；金针菇、香菇洗净切好；青菜切段。
  2. 起锅倒油，放入菌菇翻炒 2‑3 分钟。
  3. 倒入豆腐，轻轻翻炒，加少量清水、酱汁，小火焖煮 3 分钟。
  4. 放入青菜，淋水淀粉勾芡，汤汁变稠即可关火，放凉分装冷冻。

周五（4 选一轮换，推荐青椒肉丝）

直接复热第一天剩下的青椒肉丝浇头，避免额外再做菜，实现 5 个工作日全覆盖。

统一冷冻备餐流程

  1. 所有浇头彻底放凉之后再装盒。
  2. 密封保鲜盒装好，放进冰箱冷冻室，可以保存一周。
  3. 工作日：煮好米饭 → 取出一份浇头，微波炉高火加热 3‑5 分钟 → 浇到米饭上面直接食用。

6 道电饭煲一锅出 2.0

参考链接：6道「电饭煲一锅出2.0」！不开火不擦灶，搞定一周晚餐！

周一｜土豆牛肉叠叠锅

食材：牛肉片、土豆、洋葱、胡萝卜、金针菇、魔芋结 做法

  1. 电饭煲内胆底部铺上洋葱垫底；
  2. 依次放上魔芋结、金针菇、胡萝卜、土豆块，最上层铺上牛肉片；
  3. 调味：生抽、少许蚝油、黑胡椒、少量盐；不需要加水，蔬菜会出水；
  4. 盖上盖子，按下【煮饭键】；程序结束后开盖拌匀即可，配米饭。

周二｜蔬菜三文鱼叠叠锅

食材：三文鱼块、洋葱、胡萝卜、金针菇、卷心菜 做法

  1. 洋葱铺底，依次码放胡萝卜、金针菇、卷心菜；
  2. 三文鱼放在最上层，撒少许盐、黑胡椒；
  3. 无水模式，电饭煲煮饭键；
  4. 出锅汤汁可以淋到米饭上面。

周三｜电饭煲黄焖鸡

食材：鸡腿肉、香菇、胡萝卜、青椒、姜片、香料（花椒、香叶、冰糖） 做法

  1. 鸡腿肉切块，生抽、老抽、少许盐提前腌制 15‑20 分钟；
  2. 内胆放少量油、姜片打底，放入鸡块、泡发香菇；香菇泡的水加进去，水量和食材齐平；放入花椒、香叶、冰糖；
  3. 启动煮饭键；
  4. 剩余 10 分钟时，放入胡萝卜、青椒块，再焖 5 分钟即可出锅。

周四｜肉饼蒸蛋（上蒸下煮，饭肉菜一锅）

食材：猪肉末、鸡蛋、胡萝卜、马蹄（荸荠）、姜 做法

  1. 肉末 + 打碎的胡萝卜、马蹄碎、姜末，加生抽、盐搅匀，平铺在浅盘；盘子中间挖一个小坑，打入一颗鸡蛋；
  2. 电饭煲内胆淘好大米，加入煮饭的正常水量；
  3. 内胆里面放上蒸架，把肉饼盘子放在蒸架上面；
  4. 按下煮饭键；米饭蒸熟，肉饼鸡蛋同时完成；出锅淋上少许香油、葱花即可。

周五｜番茄鱼片锅

食材：龙利鱼片、番茄、洋葱、金针菇 做法

  1. 番茄切块铺底，放上洋葱、金针菇；
  2. 龙利鱼片铺顶层；放生抽、少许番茄酱、盐；
  3. 无水，电饭煲煮饭键；完成拌匀配米饭。

【备用轮换菜（第六道）】咖喱牛肉卷焖锅

食材：牛肉卷、土豆、胡萝卜、洋葱、咖喱块、少量椰浆 做法

  1. 洋葱垫底，土豆、胡萝卜铺进去，顶层放牛肉卷；
  2. 放入咖喱块 + 少量椰浆，不需要额外加水；
  3. 煮饭键焖熟，出锅搅拌均匀配米饭 / 杂粮饭。

6 道电饭煲一锅出

一周 5 天安排（周一～周五）

周一｜无水蔬菜焖鸡肉

食材：鸡腿肉、洋葱、胡萝卜、卷心菜、金针菇 做法

  1. 电饭煲内胆底部刷一点点食用油
  2. 从下往上分层铺菜：洋葱→胡萝卜→卷心菜→金针菇→鸡腿肉，最上层再盖一层卷心菜
  3. 不用加水，盖上盖子，按下【快速饭 / 煮饭】模式
  4. 程序结束后拌匀，搭配杂粮饭食用。

周二｜咖喱牛肉卷焖锅

食材：肥牛卷、土豆、胡萝卜、洋葱、咖喱块、少量椰浆 / 椰子水 做法

  1. 锅底放油，放入洋葱、土豆、胡萝卜块
  2. 放入咖喱块，倒入少量椰浆 + 清水刚好没过蔬菜
  3. 启动煮饭模式
  4. 剩余 3‑5 分钟时，把肥牛卷另外微波去血水，倒进锅里拌匀焖熟即可，配杂粮饭。

周三｜粤式蒸排骨

食材：猪排骨、荔浦芋头；调味：生抽、蚝油、少许盐、蒜末 做法

  1. 排骨泡水 30 分钟泡出血水，沥干；芋头切块
  2. 排骨 + 芋头加入调料抓匀腌制 15‑20 分钟
  3. 内胆加水，放上蒸架，排骨芋头放碗里上架
  4. 电饭煲选【原味蒸】模式，蒸 30 分钟；搭配低糖饭。

周四｜菌菇焖鸡腿锅

食材：鸡腿肉、香菇、娃娃菜、洋葱 做法

  1. 锅底刷油，底层洋葱，中层香菇、娃娃菜，顶层放鸡腿肉
  2. 无水，盖盖，煮饭模式
  3. 完成后翻拌，鸡肉汤汁和蔬菜混合，配米饭。

周五｜番茄炖牛腩

食材：牛腩、番茄、洋葱、胡萝卜，可选加土豆 做法

  1. 牛腩提前焯水；锅底放油，洋葱下锅铺底
  2. 依次放上胡萝卜、番茄块、牛腩、土豆
  3. 加少量清水、生抽，煮饭模式焖至牛腩软烂；出锅配米饭。

【备用轮换菜，周末加餐 / 替换】

杂蔬肥牛焖锅

食材：肥牛片、卷心菜、菌菇、胡萝卜 做法：蔬菜全部铺底，肥牛放在顶层，无水焖煮，煮饭模式，出锅拌匀即可。
